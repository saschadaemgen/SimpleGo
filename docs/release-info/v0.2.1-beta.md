# Release Notes: v0.2.1-beta

**Release Date:** July 15, 2026
**Previous Version:** v0.2.0-beta (March 26, 2026)
**Codename:** Server Fingerprint Rotation + Dependency Security

---

## Highlights

- **New smp.simplego.dev Server Identity** - The SimpleGo relay was rebuilt and now presents a new offline certificate. The pinned SHA-256 key hash in the firmware has been updated so devices can connect again. A v0.2.0-beta device using the default server can no longer reach it until updated to this build.
- **5 Dependency Advisories Patched (Wiki)** - The Docusaurus documentation site had five npm advisories flagged by Dependabot. All are resolved via pinned dependency overrides. `npm audit` reports zero vulnerabilities. No firmware code is affected by these advisories.

## Changes

### Server Fingerprint (SEC-07)

| Detail | Value |
|:-------|:------|
| Server | smp.simplego.dev:5223 |
| Previous key hash | eeac3886... (7qw4hvuS+PvTHbotgtg/xiwrhFUk/s1q2upUQrGIWow=) |
| New key hash | af8e49a5... (r45Jpaq2qnuZCMS4aRvppt7yCz3cj0Ha-6LUOKpfhNM=) |
| Verification | SHA-256 key hash pinning at all four TLS connection points |

The fingerprint is defined in the SimpleGo preset in `smp_servers.c`. Because the server list is cached in NVS after first boot, this change only takes effect after the NVS server list is re-initialized. See Upgrade Notes.

## Upgrade Notes

**Full erase required.** The SMP server list is stored in NVS with version-checked serialization. A normal application flash reloads the cached server list from NVS and keeps the old fingerprint, so the update would silently have no effect. Erase the flash before flashing this build:

```
idf.py erase-flash -p COM6
idf.py build flash monitor -p COM6
```

The Web Serial Installer already performs a full erase (eraseAll), so browser-based updates need no extra step.

On a correct update the boot log shows `First boot: initializing 21 preset servers` and the active server line `[20] *smp.simplego.dev SimpleGo fp=af8e...`. A `fp=eeac...` on that line means the old server list is still cached and the erase did not take effect.

## Security Status

No change to firmware security posture from v0.2.0-beta. SEC-07 (TLS fingerprint verification) remains closed and now pins the new server identity.

| ID | Status | Description |
|:---|:------:|:------------|
| SEC-01 | Open | Decrypted messages in PSRAM never zeroed |
| SEC-02 | Open | NVS keys plaintext without Vault mode |
| SEC-03 | Closed | mbedtls_platform_zeroize in smp_storage.c |
| SEC-04 | Open | No memory wipe on screen lock |
| SEC-05 | Deferred | HKDF info parameter (resolved by eFuse binding) |
| SEC-06 | Deferred | Post-quantum toggle per contact (requires SEC-01 + SEC-02) |
| SEC-07 | Closed | TLS fingerprint verification at 4 connection points |
